# موقع مؤسسة العنود

موقع تعريفي لمؤسسة العنود، متخصصة في تصليح وتنظيف الأفران بالرياض.

## هيكل الملفات

```
al-anoud-site/
├── index.html      الصفحة الرئيسية (تحتوي كل صفحات الموقع: الرئيسية، الخدمة، من نحن، اتصل بنا)
├── css/
│   └── style.css   جميع أنماط التصميم
├── js/
│   └── main.js     التنقل بين الصفحات وتحريك العدّادات
└── README.md
```

الموقع صفحة واحدة (Single Page) تتنقل بين "صفحات" مختلفة عبر جافاسكربت بدون إعادة تحميل، لذلك رفعه بسيط ولا يحتاج أي خادم أو قاعدة بيانات — ملفات ثابتة (Static) فقط.

## رفع المشروع على GitHub

1. أنشئ مستودعًا (Repository) جديدًا في حسابك على github.com، مثلًا باسم `al-anoud-site`.
2. ارفع محتويات هذا المجلد (index.html وملفي css و js) إلى المستودع، إما بالسحب والإفلات من واجهة GitHub، أو عبر الأوامر التالية من جهازك:

```bash
git init
git add .
git commit -m "أول نسخة من موقع مؤسسة العنود"
git branch -M main
git remote add origin https://github.com/USERNAME/al-anoud-site.git
git push -u origin main
```

استبدل `USERNAME` باسم حسابك على GitHub.

## تفعيل رابط مباشر (GitHub Pages)

1. داخل صفحة المستودع على GitHub، اذهب إلى **Settings**.
2. من القائمة الجانبية اختر **Pages**.
3. تحت **Branch** اختر `main` والمجلد `/ (root)`، ثم اضغط **Save**.
4. بعد دقيقة أو دقيقتين سيظهر رابط مباشر بالشكل:
   `https://USERNAME.github.io/al-anoud-site/`

هذا الرابط يعمل فورًا ويمكن مشاركته مع أي شخص.
